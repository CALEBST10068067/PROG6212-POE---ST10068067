# PROG6212-POE---ST10068067

RaceDay is a cloud-aware, API-driven event management platform built specifically for the vibrant South African road running, walking, and cycling community. From iconic events like the Comrades Marathon, Two Oceans, and Cape Town Cycle Tour to regular weekend community park runs and charity rides, endurance events in South Africa have long suffered from fragmented administrative pipelines.

RaceDay replaces legacy paper-based entry workflows and disconnected spreadsheets with a centralised, role-based platform. Organisers can create and configure events, define custom distance/age categories, and upload official timing results. Concurrently, participants can browse upcoming nationwide events, enter specific categories, and track their personal race and finish-time history.

2. System Roles
The platform enforces strict role-based access control (RBAC) across two primary user roles:

Event Organiser:

Creates, updates, and manages sporting events (locations, dates, route descriptions, distances).

Defines event-specific race categories (e.g., Ultra-marathon, Half-marathon, 10km, fun walks).

Views real-time rosters of enrolled participants per category.

Publishes and updates verified participant finish times and official placings
